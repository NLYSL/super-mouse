## 4. 风险与备选

| 风险 | 概率 | 影响 | 缓解 / Plan B |
|---|---|---|---|
| 脑机为私有协议、无文档 | 中 | 高 | nRF Connect 抓包对照眨眼找规律；最坏用设备 App 显示的眨眼值人工同步；Demo 用录制回放 + 键盘模拟 |
| 脑机只有衍生值、无原始波 | 中 | 中 | 放弃 `long_blink`，眼势只用双/三/重眨 |
| 眨眼误触发 | 高 | 中 | 校准 + 450 ms 判定窗 + 信号质量门控；Demo 期间只开双眨 + 重眨 |
| 雷达受显示器/风扇干扰 | 中 | 中 | 调整朝向、提高能量阈值、缩小探测门；`only_when_slacking` 降低误扰感知 |
| macOS 权限弹窗打断演示 | 高 | 高 | 演示机提前跑通全部流程；用同一终端 App；关闭"系统更新" |
| 场馆无网 / API 慢 | 中 | 中 | 手机热点；快路径 + 内置技能离线可跑；`api_check.py` |
| 系统光标隐藏失败 | 中 | 低 | 伴随模式 |
| 老鼠美术来不及 | 中 | 中 | 占位动画（几何老鼠）也要有表情变化；动画数量优先级：idle > alert > suggest > blink > working > happy |
| 硬件当天断线 | 低 | 高 | `⌥⌘S` 切模拟器；提前录制真实数据回放 |

## 5. Demo 脚本（3 分钟）

**场地布置**：演示机 + 外接显示器（评委看）；雷达固定在显示器顶部朝向身后过道；演示者戴脑机；第二块屏幕（或投影分屏）显示 dashboard 波形。**一名队友扮演"老板"**。

| 时间 | 画面 | 台词（示意） | 操作 / Plan B |
|---|---|---|---|
| 0:00–0:20 | 桌面，光标是一只老鼠，随光标奔跑、停下甩尾 | "这是 Super Mouse。你的光标从今天起是一只活的老鼠——它有四种超能力。" | 移动光标展示 idle/walk。PB：无 |
| 0:20–1:00 | **SHARP EYES**：dashboard 显示脑电波形，演示者眨眼老鼠同步眨眼 | "第一，它看得见你的眼睛。这是我头上的脑机读到的眼电——看，我眨眼，它也眨。" | 眨几次。PB：`F18` |
| | 双眨 → 点击打开文件夹；三眨 → 切换应用 | "双眨就是点击，三眨切换窗口，双手不用离开键盘。眼势可以自己定义。" | PB：`F13`/`F14` |
| 1:00–2:00 | **SMART BRAIN**：光标停在 Dock 的 Mail 上，老鼠举牌 | "第二，它懂我的工作。我把项目资料喂给了它。现在我只是把光标停在邮件上——它问我要不要起草回复。" | PB：快路径无网可跑 |
| | 重眨确认 → 老鼠戴安全帽工作，牌子滚动进度 → 草稿出现 → 老鼠比心 | "我用力眨一下——它就开始干活了。……三封草稿写好了，等我过目再发。" | PB：`F15` 确认；断网走内置技能 |
| 2:00–2:40 | **STRONG SENSE**：演示者打开 B 站视频摸鱼；"老板"从身后走来 | "第三，它替我盯着身后。（打开视频）现在我在摸鱼……" | "老板"从 3 m 外走近 |
| | 老鼠耳朵竖起 → 钻洞 → 屏幕瞬间切回 VS Code、静音 | "（老板到身后）——雷达发现了他，0.5 秒，屏幕回到了工作。" 老板离开后老鼠探头："回去继续？" | PB：`F16` |
| 2:40–3:00 | 第四模式概念 + 收尾 | "第四种能力（SOFT HEART）：它还关心你的眼睛和身体。Super Mouse——一只把脑机、雷达和 AI 装进光标里的老鼠。谢谢！" | 展示动画/PPT |

**演示前 10 分钟检查清单**

- [ ] 脑机电量 > 50%，电极擦拭，`poor_signal == 0`
- [ ] 雷达固定、探测区标记、无人时 dashboard 无目标
- [ ] `python tools/api_check.py` 通过；手机热点备用
- [ ] Mail 里准备好 3 封"未读邮件"；VS Code 项目路径正确
- [ ] B 站视频已缓存（避免加载）
- [ ] 系统勿扰模式开启；关闭其他会弹通知的 App；显示器不休眠
- [ ] 模拟器热键 `F13–F17` 键位贴纸；`⌥⌘S` 切换测试过
- [ ] 录屏软件运行（留底）
