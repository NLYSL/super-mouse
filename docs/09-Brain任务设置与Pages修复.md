# Brain 任务设置与 Pages 修复

## 使用

重启 Super Mouse 后，在控制面板点击 **Brain 任务设置 / 测试**。

- Pages 默认技能为 `pages_stock_report`，不依赖 AI 模型。
- 可修改报告标题、简化行情代码、输出目录、附加备注。
- **保存并生效**只保存，不执行；**保存并立即执行测试**会真实生成报告并打开 Pages。
- 正常使用：悬停 Pages Dock 图标，点击牌子或按空格确认。Pages 已在前台也可触发。
- 眼势需在绑定窗口自行选择 `brain_confirm`；保存 Brain 任务不会改动任何眼势绑定。
- 空格监听只观察，不拦截，仍会传给前台应用。
- 自定义 AI：输入应用 Bundle ID，选择 `agent`，填写任务要求。需要现有在线模型配置；应用/脚本安全限制仍然有效，并非任意应用都支持脚本操作。

## 执行与配置

统一优先级：`plans.json` 自定义任务 > `brain.apps` 应用配置 > 内置预设 > 无匹配时的 AI 建议。
`plans.json` 位于配置的 `brain.knowledge_dir` 下，默认 `~/.supermouse/brain/plans.json`。
保存采用原子替换，保留其他应用计划；文件损坏时拒绝覆盖。

设置页的报告备注原样附录，不会伪装成 AI 分析。其他技能的参数通过 JSON 对象填写。
内置报告采用行情接口数据进行确定性汇总，不包含预测或投资建议。
当前接口不提供行情时间，报告明确区分生成时间与行情时间，不承诺实时数据。

## 修复

- `brain.apps` 中技能及参数真正进入计划解析，不再只用作 Agent 白名单。
- 活跃应用的 Dock 图标不再误过滤；鼠标移向牌子不会立即撤销已显示的建议。
- 新悬停取消旧 AI 建议；未知命名技能报错，不静默转成 Agent。
- Pages 路径：生成 RTF → 系统 textutil 转 DOCX → AppleScript 导入 Pages → 检查返回的文档引用。
- 状态分为 done / partial / error，并携带结果文件路径；数据缺失、应用打开失败不再报成功。
- AI 通用任务结果显示“需人工核验”，不把模型自述视为实际完成证明。
- 中止后等待后台线程实际退出才允许新任务，防止上下文串用；不能撤销已经完成的系统操作。
- Pages 加入 Agent 应用及脚本名称白名单，原有危险动作限制保留。

如文件已生成但 Pages 未确认打开，查看设置页错误及系统设置 → 隐私与安全性 → 自动化，检查运行 Super Mouse 的进程是否获准控制 Pages。
