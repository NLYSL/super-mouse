## 3. 脑机接入

### 3.1 BLE 基础（bleak on macOS）

- macOS 用 CoreBluetooth，**设备标识是系统分配的 UUID**，换电脑会变；配置里按 `name_prefix` 匹配更稳。
- 默认 MTU 下每次 notify 约 20 字节，数据帧会被**任意切分**，解析必须是**字节流状态机**，不能假定一次回调就是一帧。
- 扫描需要几秒；连接后要处理断线重连（`disconnected_callback`）。

```python
# tools/ble_scan.py
import asyncio
from bleak import BleakScanner

async def main():
    found = await BleakScanner.discover(timeout=6.0, return_adv=True)
    for dev, adv in found.values():
        print(f"{dev.address}  {dev.name!s:24} rssi={adv.rssi:4}  services={adv.service_uuids}")

asyncio.run(main())
```

```python
# tools/ble_dump.py <address> [notify_uuid]
import asyncio, sys
from bleak import BleakClient

async def main(address, uuid=None):
    async with BleakClient(address) as client:
        for svc in client.services:
            print("SERVICE", svc.uuid, svc.description)
            for ch in svc.characteristics:
                print("   CHAR", ch.uuid, ch.properties)
                if uuid is None and "notify" in ch.properties:
                    uuid = ch.uuid                      # 默认订阅第一个 notify 特征
        def on_data(_, data: bytearray):
            print(data.hex(" "))
        await client.start_notify(uuid, on_data)
        await asyncio.sleep(30)

asyncio.run(main(sys.argv[1], sys.argv[2] if len(sys.argv) > 2 else None))
```

常见透传服务 UUID：Nordic UART `6e400001-b5a3-f393-e0a9-e50e24dcca9e`（TX notify `6e400003-...`）、HM-10 系 `0000ffe0-.../0000ffe1-...`。

### 3.2 协议识别决策树

```
notify 数据流
 ├─ 含大量 "AA AA <len> ... <chk>" → ThinkGear (§3.3)
 │     ├─ 有 0x80 码（2 字节原始波，~512 帧/秒）→ 走 §3.4 自研眨眼检测 + 设备 0x16 眨眼双保险
 │     └─ 只有 0x02/0x04/0x05/0x16 等衍生值（1 帧/秒）→ 只能用设备眨眼强度，long_blink 不可用
 ├─ 厂商有 Python/JS SDK 或协议文档 → 按文档写 vendor_xxx.py，输出同样的事件
 ├─ 厂商只有手机 SDK → 用 nRF Connect 记录、对照眨眼时刻找规律（通常 2 字节有符号大端原始波）
 └─ 系统蓝牙里出现为经典蓝牙串口 → 配对后 pyserial 打开 /dev/tty.<设备名>-SPP，字节流同上
```

### 3.3 ThinkGear 协议（若适用）

包格式：`0xAA 0xAA | PLENGTH(1) | PAYLOAD(PLENGTH) | CHKSUM(1)`，`CHKSUM = (~sum(PAYLOAD)) & 0xFF`，PLENGTH ≤ 169。

PAYLOAD 是若干 `[CODE][LEN 可选][VALUE]` 行：`CODE < 0x80` 为单字节值，`CODE ≥ 0x80` 后跟 1 字节长度。

| CODE | 名称 | 长度 | 含义 |
|---|---|---|---|
| `0x02` | POOR_SIGNAL | 1 | 0 = 良好，200 = 未接触皮肤 |
| `0x04` | ATTENTION | 1 | 专注度 0–100 |
| `0x05` | MEDITATION | 1 | 放松度 0–100 |
| `0x16` | BLINK_STRENGTH | 1 | 眨眼强度 1–255（有的固件不发） |
| `0x80` | RAW_WAVE | 2 | 有符号 16 位大端原始 EEG，512 Hz |
| `0x83` | ASIC_EEG_POWER | 24 | 8 频段 × 3 字节 |
| `0x55` | EXCODE | — | 扩展码前缀，忽略 |

```python
# devices/bci/thinkgear.py
class ThinkGearParser:
    def __init__(self):
        self.buf = bytearray()

    def feed(self, data: bytes):
        """喂入任意切分的字节，产出 (name, value) 元组。"""
        self.buf += data
        while True:
            i = self.buf.find(b"\xaa\xaa")
            if i < 0:
                self.buf.clear(); return
            if len(self.buf) < i + 3:
                del self.buf[:i]; return
            plen = self.buf[i + 2]
            if plen > 169:                        # 假同步头，跳过一字节重找
                del self.buf[: i + 1]; continue
            end = i + 3 + plen + 1
            if len(self.buf) < end:
                del self.buf[:i]; return
            payload = bytes(self.buf[i + 3 : i + 3 + plen]); chk = self.buf[end - 1]
            del self.buf[:end]
            if ((~sum(payload)) & 0xFF) != chk:
                continue
            yield from self._rows(payload)

    def _rows(self, p: bytes):
        j = 0
        while j < len(p):
            code = p[j]; j += 1
            while code == 0x55:                   # EXCODE
                code = p[j]; j += 1
            if code >= 0x80:
                n = p[j]; j += 1
            else:
                n = 1
            v = p[j : j + n]; j += n
            if   code == 0x02: yield ("poor_signal", v[0])
            elif code == 0x04: yield ("attention", v[0])
            elif code == 0x05: yield ("meditation", v[0])
            elif code == 0x16: yield ("blink", v[0])
            elif code == 0x80: yield ("raw", int.from_bytes(v, "big", signed=True))
            elif code == 0x83: yield ("eeg_power", v)
```

事件映射：`poor_signal → bci.quality`；`blink → bci.blink(strength=v/255, duration_ms=None, source="device")`；`raw` 批量 32 个样本 → `bci.raw` 并送入 §3.4 检测器；`attention → bci.attention`。

### 3.4 原始 EEG 眨眼检测算法

**原理**：前额电极离眼睛很近，眨眼产生的眼电（EOG）伪迹幅度（100–500 μV）远大于脑电本身（10–50 μV），表现为 0.5–8 Hz 的大幅慢波尖峰，持续 100–400 ms。用力眨眼幅度更大、时间更长。

**流水线**（每 32 样本处理一次，延迟 ≈ 62 ms + 峰后判定）：

1. 去直流 + 带通 0.5–8 Hz（2 阶 Butterworth，`sosfilt` 带状态，流式）；
2. 自适应阈值：最近 5 s 滤波信号的中位数 + k × MAD（k ≈ 5，校准后改用绝对阈值）；
3. 幅度超过阈值进入"眨眼中"，跟踪峰值与起止时刻；回落到阈值一半以下结束；
4. 时长 50–800 ms 且距上次 ≥ 150 ms（不应期）→ 发出 `bci.blink(strength, duration_ms)`；
5. `strength = clip(peak / calib.intent_peak, 0, 1)`，校准前用 `peak / (阈值 × 3)`。

> 极性：眨眼在 Fp1-耳参考上通常是正向偏转，但设备可能反相。实现上取 `abs()` 判幅度，校准时记录主极性以便进一步抑制 EEG 噪声。

```python
# devices/bci/blink_detector.py
from collections import deque
import numpy as np
from scipy.signal import butter, sosfilt, sosfilt_zi

class BlinkDetector:
    def __init__(self, fs=512, band=(0.5, 8.0), k=5.0, refractory_ms=150,
                 min_ms=50, max_ms=800, abs_threshold=None, intent_peak=None):
        self.fs = fs
        self.sos = butter(2, band, btype="band", fs=fs, output="sos")
        self.zi = sosfilt_zi(self.sos) * 0.0
        self.k, self.abs_thr, self.intent_peak = k, abs_threshold, intent_peak
        self.refractory, self.min_len, self.max_len = int(fs*refractory_ms/1000), int(fs*min_ms/1000), int(fs*max_ms/1000)
        self.hist = deque(maxlen=fs * 5)
        self.n = 0; self.in_blink = False; self.start = 0; self.peak = 0.0; self.last_end = -10**9

    def threshold(self):
        if self.abs_thr: return self.abs_thr
        if len(self.hist) < self.fs: return float("inf")
        a = np.abs(np.fromiter(self.hist, float))
        med = np.median(a); mad = np.median(np.abs(a - med)) + 1e-6
        return med + self.k * 1.4826 * mad

    def feed(self, samples):
        """返回本批检测到的眨眼列表 [(t_index, strength, duration_ms)]"""
        y, self.zi = sosfilt(self.sos, np.asarray(samples, float), zi=self.zi)
        out = []; thr = self.threshold()
        for v in y:
            self.n += 1; a = abs(v); self.hist.append(v)
            if not self.in_blink:
                if a > thr and self.n - self.last_end > self.refractory:
                    self.in_blink, self.start, self.peak = True, self.n, a
            else:
                self.peak = max(self.peak, a)
                if a < thr * 0.5:
                    length = self.n - self.start; self.in_blink = False; self.last_end = self.n
                    if self.min_len <= length <= self.max_len:
                        ref = self.intent_peak or thr * 3
                        out.append((self.n, min(self.peak / ref, 1.0), length * 1000 / self.fs))
        return out
```

### 3.5 校准（modes/sharp_eyes/calibration.py）

| 阶段 | 时长 | 采集 | 计算 |
|---|---|---|---|
| 信号就绪 | ≤ 30 s | `poor_signal == 0` 持续 3 s | — |
| 自然 | 20 s | 所有 `bci.blink` 的 peak | `natural_p95` |
| 意图（用力眨 ×10） | ~15 s | peak | `intent_p50`，`intent_peak = intent_p90` |
| 节奏（快速双眨 ×5） | ~15 s | 相邻眨眼间隔 | `double_gap = [p5 × 0.8, p95 × 1.2]`，限制在 [100, 500] ms |

- `hard_threshold = (natural_p95 + intent_p50) / 2`（归一化到 intent_peak 后写入 config）。
- `abs_threshold = natural 阶段滤波信号 MAD × k`，写入 config 后检测器不再用自适应阈值（更稳定）。
- 校准结果不理想（两分布重叠 > 30%）→ 提示重新贴电极。

### 3.6 眼势识别状态机（modes/sharp_eyes/gestures.py）

规则：缓冲眨眼，**静默 450 ms 后判定**（避免"重眨"和"双眨的第一下"冲突）；`long_blink` 在眨眼结束时立即判定。

```python
class GestureRecognizer:
    def __init__(self, bus, gap=(0.12, 0.45), hard_thr=0.55, long_ms=400, refractory=0.5):
        self.bus, self.gap, self.hard_thr, self.long_ms, self.refractory = bus, gap, hard_thr, long_ms, refractory
        self.buf: list[tuple[float, float]] = []      # (t, strength)
        self.last_gesture_t = 0.0; self.timer = None

    def on_blink(self, t, strength, duration_ms):
        if duration_ms and duration_ms >= self.long_ms:
            self.buf.clear(); return self._emit("long_blink", t)
        if self.buf and not (self.gap[0] <= t - self.buf[-1][0] <= self.gap[1] + 0.3):
            self.buf.clear()
        self.buf.append((t, strength))
        self._arm_timer(self.gap[1])                  # 450 ms 无新眨眼 → decide()

    def decide(self):
        n = len(self.buf); t = self.buf[-1][0]
        if n >= 3:   g = "triple_blink"
        elif n == 2 and self.gap[0] <= self.buf[1][0] - self.buf[0][0] <= self.gap[1]: g = "double_blink"
        elif n == 1 and self.buf[0][1] >= self.hard_thr: g = "hard_blink"
        else: g = None                                # 单次普通眨眼：忽略
        self.buf.clear()
        if g: self._emit(g, t)

    def _emit(self, gesture, t):
        if t - self.last_gesture_t < self.refractory: return
        self.last_gesture_t = t
        self.bus.publish("eye.gesture", gesture=gesture)
```

门控：`bci.quality.poor_signal > 50` 时丢弃所有眨眼；`eyes.enabled == false` 时只发 `blink_mirror` 不发手势。

### 3.7 验收

- 自然使用 5 分钟：`eye.gesture` 事件 ≤ 1 次。
- 连做 20 次双眨：识别 ≥ 17 次（85%）。
- 连做 10 次重眨：识别 ≥ 8 次，且不被判成双眨。

### 4.2 主机文本格式

```text

```

详见 [适配记录](08-S3雷达主机适配.md)。

### 4.3 抓包与驱动


### 4.4 安装位置和人数阈值

用户已确认探测范围包含本人，当前阈值是 2。仅当探测区不包含本人时才改成 1。
统计 zone_m 上限内所有有效目标，近处本人即使低于 zone_m 下限也计数。
距离按从近到远排序，阈值前的目标视作人数基线，再取区内最近来人的距离。
这不是身份识别，也不把协议槽位当成固定的人；静止本人可能丢失跟踪，须实测。

### 4.5 入侵判定

`sense.intruder_target_count=2` 为主判据；连续 `min_frames=3` 帧后触发，
接近速度只决定事件的 approaching 字段，不绕过连续帧门槛。
一个人、空帧、区域外第二人均不触发；多目标不依赖伪造的能量值。

持续满足条件不重复触发；低于人数阈值连续 `clear_s=10` 秒后 clear，
只剩本人也算清空。重新出现受 `cooldown_s=20` 秒限制。
帧间隔超过 `max_frame_gap_s=0.5` 或断线后重新累计证据，不把静默当无人。
单目标协议仅在阈值 1 时兼容旧距离/能量判定，不能从 moving/static 推导两个人。
事件字段不变：`sense.intruder(distance_m, approaching)` / `sense.clear()`。

## 6. 故障排查 FAQ

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `ble_scan` 扫不到 | 设备未开机/未进入广播；终端无蓝牙权限；设备被手机 App 占用 | 关掉手机 App；系统设置授权；重启蓝牙 |
| 连接成功但无数据 | 订阅了错误特征；设备需要先写"开始"命令 | nRF Connect 逐个订阅；查手册是否需写入启动指令 |
| ThinkGear 校验大量失败 | 帧被切分后解析未做流式处理 | 用 §3.3 的缓冲解析器 |
| `poor_signal` 一直 200 | 电极未贴皮肤/头发夹住/耳夹没夹 | 酒精擦拭额头，调整佩戴 |
| 眨眼检测太多误报 | 说话/皱眉/咀嚼 EMG 伪迹 | 提高 k；限制时长上限；校准阶段保持安静 |
| 串口无节点 | 驱动/线材只供电不传数据 | 换线；`system_profiler SPUSBDataType` 看是否枚举 |
| 雷达乱码 | 波特率不对；TX/RX 反接 | 试 115200/9600；交换 TX/RX |
| 雷达无人也报运动 | 显示器/风扇/窗帘；能量阈值过低 | 调整朝向；能量阈值 +15；缩小最远门 |
| 老鼠钻洞太慢 | AppleScript 首次调用慢、未预授权 | 演示前预热一次 `hide_app`；用 `open -b` 代替 AppleScript 激活 |
