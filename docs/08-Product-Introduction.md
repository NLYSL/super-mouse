# 🐭 SUPER MOUSE — 让光标活过来

> 一只住在你鼠标光标里的老鼠：它看得见你的眼睛，懂你的工作，还替你盯着身后。

**SUPER MOUSE** 是一个运行在 macOS 上的"光标伙伴"。系统光标被替换成一只有表情、有动作的卡通老鼠，并通过**脑机接口、毫米波雷达与大语言模型**三种感知通道，赋予它三种超能力——你不再操作光标，光标本身成为你的交互代理。

## 三种超能力

### 👀 SHARP EYES — 眨眼即指令

前额叶三电极脑机实时读取你的眼电信号（250 Hz），区分**自然眨眼**与**有意眨眼**：

- **60 秒校准**：自然眨眼 → 用力眨眼 → 双眨节奏，三阶段采集你的个人特征，阈值全自动计算
- **眼势词表**：双眨、三眨、用力眨、长眨——四种"眼势"可绑定任意快捷键
- **先做眼势、再按热键**的绑定向导，双手不离键盘完成全部设置
- 出厂不预设任何映射：设备不会在你没同意前替你点击任何东西

**技术要点**：实测标定的参数而非拍脑袋——自然眨眼时长 68–132ms、用力眨 184–284ms，两类分布靠时长即可完全分离；带通滤波 + 自适应阈值 + 极性判定，眨眼检测零误触发（14 次自然眨眼全部计数、无一误判）。

### 🧠 SUPER BRAIN — 悬停即代办

把光标停在应用图标上 0.7 秒，老鼠举起小牌子问你要不要代劳；**按下空格**确认，它就开始干活：

- **Pages 股票报告**（演示招牌）：光标放到桌面的 Pages 替身上 → 老鼠举牌"写一份今日股票报告？" → 空格 → 自动抓取四指数实时行情 → 排版生成文稿 → Pages 打开。**全程不需要任何 AI API**
- 内置技能：Mail 起草回复（只存草稿不发送）、Notes 日报、Chrome 早间标签页、任意文档总结
- **脑设置面板**：给任何 App 绑定内置技能，或写自定义 AI 指令
- 双后端：DeepSeek（默认）与 Claude 一键切换；无 API 时全部退化为离线技能

**交互设计**：所有确认方式等价——空格、点击牌子、用力眨眼，走的同一条事件链路。

### 📡 STRONG SENSE — 身后有人，瞬间切屏

海凌科 HLK-LD2454 24GHz 毫米波雷达持续追踪探测区内目标（16 帧/秒，最多 3 目标坐标）：

- **人头数判定**：你坐在电脑前 = 1 个目标；**目标数变成 2 = 有人走近**
- 有人靠近 → 隐藏摸鱼应用 → 切回你绑定的**全屏工作页** → 静音 → 老鼠钻进洞里
- 人走开 → 老鼠探出头："回去继续？" → 空格恢复原状
- **⌃⌥B** 一键绑定当前 App 为工作页（全屏 App 里也能按，老鼠举牌确认）；热键可自定义
- 面板实时显示目标数，从"目标 1（你）"变红成"目标 2"的一刻肉眼可见

**实测依据**：单人静坐基线 163 帧零跳变；走动目标会被雷达间歇性丢失——判定用 2 秒滑窗计数而非连续计数，来人边走边靠近也能稳定触发。

## 为什么是"一只老鼠"而不是三个功能

所有感知都汇入同一只老鼠的身体语言：你眨眼它眨眼（脑电数据可见的最直接证据）、干活时戴安全帽、有人来时钻洞。**它不是仪表盘，是一个有反应的生命体**——评委或用户不需要读文档，看它的表情就知道系统在"想"什么。

架构上，一切皆事件：脑机、雷达、AI 之间通过统一事件总线通信，任何一环都可以被热键模拟器替换（`--sim` 模式无硬件可完整演示）、被录制回放（演示保险）。

## 硬件清单

| 设备 | 角色 | 接入 |
|---|---|---|
| 前额叶三电极脑机 | SHARP EYES | USB 接收器 → 串口，即插即用 |
| HLK-LD2454 毫米波雷达 | STRONG SENSE | 立创 ESP32-S3（板上 MicroPython 固件）读雷达 → USB 串口 |
| Mac | 全部逻辑 | 蓝牙/串口驱动装好后零配置 |

## 快速开始

```bash
git clone https://github.com/NLYSL/super-mouse && cd super-mouse
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

python tools/api_check.py --quick   # 自检
python -m supermouse --debug        # 启动
```

无硬件演示：`python -m supermouse --sim --debug`（热键模拟眨眼与雷达事件）。
